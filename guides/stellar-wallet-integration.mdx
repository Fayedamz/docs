Wraith's demo ships multi-wallet support for the four main Stellar browser wallets. This guide shows you how to integrate each one, build a wallet picker, persist sessions, and handle mobile users.

## Supported Wallets

| Wallet | Type | Soroban Auth | Fee-bump Signing | Mobile | Install Required |
|---|---|---|---|---|---|
| **Freighter** | Browser extension | ✅ | ✅ | ❌ | Yes |
| **Albedo** | Web (iframe) | ✅ | ✅ | ✅ (web) | No |
| **xBull** | Browser extension | ✅ | ✅ | ✅ (PWA) | Yes |
| **LOBSTR** | Mobile + extension | ✅ | ❌ | ✅ | Yes |
| **WalletConnect v2** | Protocol | ✅ | ✅ | ✅ | No |

```bash
npm install @stellar/stellar-sdk @wraith-protocol/sdk
```

## Freighter

[Freighter](https://www.freighter.app) is the most widely used Stellar browser extension. It supports full Soroban auth and fee-bump signing.

### Install and connect

```typescript
import {
  isConnected,
  requestAccess,
  getPublicKey,
  signTransaction,
  signAuthEntry,
} from "@stellar/freighter-api";

async function connectFreighter(): Promise<string> {
  const connected = await isConnected();
  if (!connected) {
    throw new Error("Freighter extension not installed");
  }

  // Prompt user to grant access
  const accessResult = await requestAccess();
  if (accessResult.error) {
    throw new Error(accessResult.error);
  }

  const pubkeyResult = await getPublicKey();
  if (pubkeyResult.error) {
    throw new Error(pubkeyResult.error);
  }

  return pubkeyResult.publicKey; // "G..."
}
```

### Sign a transaction

```typescript
import { signTransaction } from "@stellar/freighter-api";

async function signWithFreighter(xdr: string, networkPassphrase: string): Promise<string> {
  const result = await signTransaction(xdr, { networkPassphrase });
  if (result.error) throw new Error(result.error);
  return result.signedTxXdr;
}
```

### Derive stealth keys with Freighter

```typescript
import { STEALTH_SIGNING_MESSAGE } from "@wraith-protocol/sdk/chains/stellar";
import { signMessage } from "@stellar/freighter-api";

async function deriveKeysWithFreighter() {
  const result = await signMessage(STEALTH_SIGNING_MESSAGE, {
    networkPassphrase: "Test SDF Network ; September 2015",
  });
  if (result.error) throw new Error(result.error);

  // result.signedMessage is a base64-encoded 64-byte ed25519 signature
  const sigBytes = Buffer.from(result.signedMessage, "base64");

  const { deriveStealthKeys } = await import("@wraith-protocol/sdk/chains/stellar");
  return deriveStealthKeys(sigBytes);
}
```

### Check if Freighter is installed

```typescript
import { isConnected } from "@stellar/freighter-api";

const available = await isConnected();
// false if extension not installed — show install prompt
```

## Albedo

[Albedo](https://albedo.link) runs entirely in an iframe — no extension required. It works in any browser and on mobile web.

### Connect

```typescript
import albedo from "albedo-link";

async function connectAlbedo(): Promise<string> {
  const result = await albedo.publicKey({
    require_existing: false,
  });
  return result.pubkey; // "G..."
}
```

### Sign a transaction

```typescript
import albedo from "albedo-link";

async function signWithAlbedo(xdr: string, network: string): Promise<string> {
  const result = await albedo.tx({
    xdr,
    network,        // "testnet" | "public"
    submit: false,  // return signed XDR, don't auto-submit
  });
  return result.signed_envelope_xdr;
}
```

### Derive stealth keys with Albedo

```typescript
import albedo from "albedo-link";
import { deriveStealthKeys, STEALTH_SIGNING_MESSAGE } from "@wraith-protocol/sdk/chains/stellar";

async function deriveKeysWithAlbedo() {
  // Albedo's message signing returns a hex-encoded signature
  const result = await albedo.signMessage({
    message: STEALTH_SIGNING_MESSAGE,
  });

  const sigBytes = Buffer.from(result.message_signature, "hex");
  return deriveStealthKeys(sigBytes);
}
```

### Albedo notes

- No install required — best fallback for users without an extension
- Session token can be persisted (see [Session Persistence](#session-persistence))
- Popup-based UX — some browsers may block it without a direct user gesture

## xBull

[xBull](https://xbull.app) is a browser extension and PWA with full Soroban support.

### Connect

```typescript
import { xBullWalletConnect } from "@xbull/sdk";

const xbull = new xBullWalletConnect();

async function connectXBull(): Promise<string> {
  await xbull.connect();
  const publicKey = await xbull.getPublicKey();
  return publicKey; // "G..."
}
```

### Sign a transaction

```typescript
async function signWithXBull(xdr: string): Promise<string> {
  const signedXdr = await xbull.sign({ xdr, publicKey });
  return signedXdr;
}
```

### Derive stealth keys with xBull

```typescript
import { deriveStealthKeys, STEALTH_SIGNING_MESSAGE } from "@wraith-protocol/sdk/chains/stellar";

async function deriveKeysWithXBull() {
  const result = await xbull.signMessage({
    message: STEALTH_SIGNING_MESSAGE,
  });

  const sigBytes = Buffer.from(result.signature, "hex");
  return deriveStealthKeys(sigBytes);
}
```

### Disconnect

```typescript
await xbull.disconnect();
```

## LOBSTR

[LOBSTR](https://lobstr.co) is primarily a mobile wallet with a companion browser extension. It does not support fee-bump signing.

### Connect

```typescript
import { lobstrSignTransaction, getLobstrPublicKey } from "@lobstrco/signer-extension-api";

async function connectLOBSTR(): Promise<string> {
  const publicKey = await getLobstrPublicKey();
  return publicKey; // "G..."
}
```

### Sign a transaction

```typescript
import { lobstrSignTransaction } from "@lobstrco/signer-extension-api";

async function signWithLOBSTR(xdr: string): Promise<string> {
  const signedXdr = await lobstrSignTransaction(xdr);
  return signedXdr;
}
```

### LOBSTR notes

- Fee-bump signing is **not supported** — don't use LOBSTR as a fee sponsor
- Best suited for mobile-first users who have the LOBSTR mobile app
- The browser extension acts as a bridge to the mobile app — both must be installed

## Building a Wallet Picker

The demo's `StellarWalletPicker` component is a good reference. Here's the pattern:

### Wallet descriptor type

```typescript
export type StellarWalletId = "freighter" | "albedo" | "xbull" | "lobstr";

export interface StellarWallet {
  id: StellarWalletId;
  name: string;
  icon: string;           // URL or inline SVG
  downloadUrl: string;
  requiresExtension: boolean;
  connect: () => Promise<string>;         // returns public key
  signTransaction: (xdr: string) => Promise<string>;
  signMessage: (message: string) => Promise<Uint8Array>;
  isAvailable: () => Promise<boolean>;
}
```

### Wallet registry

```typescript
import { isConnected as freighterIsConnected } from "@stellar/freighter-api";
import albedo from "albedo-link";
import { xBullWalletConnect } from "@xbull/sdk";
import { getLobstrPublicKey } from "@lobstrco/signer-extension-api";

export const STELLAR_WALLETS: StellarWallet[] = [
  {
    id: "freighter",
    name: "Freighter",
    icon: "/wallets/freighter.svg",
    downloadUrl: "https://www.freighter.app",
    requiresExtension: true,
    isAvailable: async () => (await freighterIsConnected()).isConnected,
    connect: connectFreighter,
    signTransaction: (xdr) => signWithFreighter(xdr, networkPassphrase),
    signMessage: async (msg) => {
      const { signMessage } = await import("@stellar/freighter-api");
      const res = await signMessage(msg, { networkPassphrase });
      return Buffer.from(res.signedMessage, "base64");
    },
  },
  {
    id: "albedo",
    name: "Albedo",
    icon: "/wallets/albedo.svg",
    downloadUrl: "https://albedo.link",
    requiresExtension: false,
    isAvailable: async () => true, // always available
    connect: connectAlbedo,
    signTransaction: (xdr) => signWithAlbedo(xdr, "testnet"),
    signMessage: async (msg) => {
      const res = await albedo.signMessage({ message: msg });
      return Buffer.from(res.message_signature, "hex");
    },
  },
  {
    id: "xbull",
    name: "xBull",
    icon: "/wallets/xbull.svg",
    downloadUrl: "https://xbull.app",
    requiresExtension: true,
    isAvailable: async () => {
      try {
        const xb = new xBullWalletConnect();
        await xb.connect();
        return true;
      } catch {
        return false;
      }
    },
    connect: connectXBull,
    signTransaction: (xdr) => signWithXBull(xdr),
    signMessage: async (msg) => {
      const res = await xbull.signMessage({ message: msg });
      return Buffer.from(res.signature, "hex");
    },
  },
  {
    id: "lobstr",
    name: "LOBSTR",
    icon: "/wallets/lobstr.svg",
    downloadUrl: "https://lobstr.co",
    requiresExtension: true,
    isAvailable: async () => {
      try {
        await getLobstrPublicKey();
        return true;
      } catch {
        return false;
      }
    },
    connect: connectLOBSTR,
    signTransaction: signWithLOBSTR,
    signMessage: async (_msg) => {
      throw new Error("LOBSTR does not support message signing");
    },
  },
];
```

### Wallet picker React component

```tsx
import { useState, useEffect } from "react";
import { STELLAR_WALLETS, StellarWallet, StellarWalletId } from "./wallets";

interface WalletPickerProps {
  onConnect: (walletId: StellarWalletId, publicKey: string) => void;
}

export function StellarWalletPicker({ onConnect }: WalletPickerProps) {
  const [availability, setAvailability] = useState<Record<string, boolean>>({});

  useEffect(() => {
    Promise.all(
      STELLAR_WALLETS.map(async (w) => ({
        id: w.id,
        available: await w.isAvailable(),
      }))
    ).then((results) => {
      setAvailability(Object.fromEntries(results.map((r) => [r.id, r.available])));
    });
  }, []);

  async function handleConnect(wallet: StellarWallet) {
    const publicKey = await wallet.connect();
    onConnect(wallet.id, publicKey);
  }

  return (
    <div className="wallet-picker">
      {STELLAR_WALLETS.map((wallet) => {
        const available = availability[wallet.id] ?? false;
        return (
          <button
            key={wallet.id}
            onClick={() => (available ? handleConnect(wallet) : window.open(wallet.downloadUrl))}
            className={available ? "wallet-btn available" : "wallet-btn install"}
            aria-label={available ? `Connect ${wallet.name}` : `Install ${wallet.name}`}
          >
            <img src={wallet.icon} alt={wallet.name} width={32} height={32} />
            <span>{wallet.name}</span>
            {!available && wallet.requiresExtension && (
              <span className="badge">Install</span>
            )}
          </button>
        );
      })}
    </div>
  );
}
```

### Hooking the picker into Wraith key derivation

```typescript
import { deriveStealthKeys, STEALTH_SIGNING_MESSAGE } from "@wraith-protocol/sdk/chains/stellar";
import { STELLAR_WALLETS } from "./wallets";

async function connectAndDeriveKeys(walletId: StellarWalletId) {
  const wallet = STELLAR_WALLETS.find((w) => w.id === walletId)!;

  const publicKey = await wallet.connect();
  const sigBytes = await wallet.signMessage(STEALTH_SIGNING_MESSAGE);
  const keys = deriveStealthKeys(sigBytes);

  return { publicKey, keys };
}
```

## Stellar Wallets Kit (Alternative)

[Stellar Wallets Kit](https://github.com/Creit-Tech/Stellar-Wallets-Kit) is a community library that abstracts all Stellar wallets behind a single interface — less boilerplate than managing each wallet separately.

```bash
npm install @creit.tech/stellar-wallets-kit
```

### Setup

```typescript
import {
  StellarWalletsKit,
  WalletNetwork,
  FREIGHTER_ID,
  ALBEDO_ID,
  XBULL_ID,
  allowAllModules,
} from "@creit.tech/stellar-wallets-kit";

const kit = new StellarWalletsKit({
  network: WalletNetwork.TESTNET,
  selectedWalletId: FREIGHTER_ID,
  modules: allowAllModules(),
});
```

### Open built-in modal

```typescript
await kit.openModal({
  onWalletSelected: async (option) => {
    kit.setWallet(option.id);
    const { address } = await kit.getAddress();
    console.log(address); // "G..."
  },
});
```

### Sign a transaction

```typescript
const { signedTxXdr } = await kit.signTransaction(unsignedXdr);
```

### Derive stealth keys via kit

```typescript
import { STEALTH_SIGNING_MESSAGE, deriveStealthKeys } from "@wraith-protocol/sdk/chains/stellar";

const { signedMessage } = await kit.signMessage(STEALTH_SIGNING_MESSAGE);
const sigBytes = Buffer.from(signedMessage, "base64");
const keys = deriveStealthKeys(sigBytes);
```

### Kit vs manual integration

| | Manual | Stellar Wallets Kit |
|---|---|---|
| Setup | Per-wallet packages | One package |
| Bundle size | Smaller (tree-shakeable) | Larger (all wallets) |
| UI | Bring your own | Built-in modal |
| Customization | Full control | Limited styling |
| New wallets | Manual update | Library update |

Use the kit for fast integration. Use the manual approach when you need custom UI or want to minimize bundle size.

## Session Persistence

Prompting users to reconnect every page load degrades UX. Persist wallet choice and public key in `localStorage` and re-verify silently on load.

```typescript
const SESSION_KEY = "wraith:stellar:session";

interface StellarSession {
  walletId: StellarWalletId;
  publicKey: string;
  connectedAt: number;
}

// Save session after successful connect
function saveSession(walletId: StellarWalletId, publicKey: string) {
  const session: StellarSession = {
    walletId,
    publicKey,
    connectedAt: Date.now(),
  };
  localStorage.setItem(SESSION_KEY, JSON.stringify(session));
}

// Restore session on app load
async function restoreSession(): Promise<StellarSession | null> {
  const raw = localStorage.getItem(SESSION_KEY);
  if (!raw) return null;

  const session: StellarSession = JSON.parse(raw);

  // Verify the wallet is still connected and key matches
  const wallet = STELLAR_WALLETS.find((w) => w.id === session.walletId);
  if (!wallet) return null;

  try {
    const available = await wallet.isAvailable();
    if (!available) {
      clearSession();
      return null;
    }

    // Re-confirm public key matches (catches account switches)
    const currentKey = await wallet.connect();
    if (currentKey !== session.publicKey) {
      clearSession();
      return null;
    }

    return session;
  } catch {
    clearSession();
    return null;
  }
}

function clearSession() {
  localStorage.removeItem(SESSION_KEY);
}
```

### Using session in a React app

```tsx
import { useEffect, useState } from "react";

export function useWalletSession() {
  const [session, setSession] = useState<StellarSession | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    restoreSession().then((s) => {
      setSession(s);
      setLoading(false);
    });
  }, []);

  async function connect(walletId: StellarWalletId) {
    const wallet = STELLAR_WALLETS.find((w) => w.id === walletId)!;
    const publicKey = await wallet.connect();
    saveSession(walletId, publicKey);
    setSession({ walletId, publicKey, connectedAt: Date.now() });
  }

  function disconnect() {
    clearSession();
    setSession(null);
  }

  return { session, loading, connect, disconnect };
}
```

## Mobile Wallet Considerations

Most Stellar browser extensions don't run on mobile. Plan for this explicitly.

### Detection pattern

```typescript
function isMobile(): boolean {
  return /Mobi|Android|iPhone|iPad/i.test(navigator.userAgent);
}

function getRecommendedWallets(): StellarWallet[] {
  if (isMobile()) {
    // Albedo (web) and LOBSTR (mobile) work on mobile
    return STELLAR_WALLETS.filter((w) => !w.requiresExtension || w.id === "lobstr");
  }
  return STELLAR_WALLETS;
}
```

### Mobile wallet matrix

| Wallet | iOS | Android | Notes |
|---|---|---|---|
| Freighter | ❌ | ❌ | Desktop extension only |
| Albedo | ✅ | ✅ | Web-based, works in any browser |
| xBull | ✅ | ✅ | PWA available |
| LOBSTR | ✅ | ✅ | Native app + extension bridge |
| WalletConnect v2 | ✅ | ✅ | Deep link / QR code (coming soon) |

### Recommended mobile flow

```tsx
function WalletPickerAdaptive({ onConnect }) {
  const mobile = isMobile();
  const wallets = getRecommendedWallets();

  return (
    <div>
      {mobile && (
        <p className="hint">
          On mobile, use Albedo or LOBSTR. WalletConnect coming soon.
        </p>
      )}
      {wallets.map((wallet) => (
        <WalletButton key={wallet.id} wallet={wallet} onConnect={onConnect} />
      ))}
    </div>
  );
}
```

### Deep link fallback for LOBSTR on mobile

When the LOBSTR extension isn't available, you can prompt users to open the LOBSTR mobile app directly:

```typescript
function openLobstrMobile(xdr: string) {
  const encoded = encodeURIComponent(xdr);
  window.location.href = `lobstr://sign?xdr=${encoded}`;
}
```
